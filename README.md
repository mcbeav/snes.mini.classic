<h1>SNES Mini Classic Custom Theming Assets</h1>

<p>These are the assets I created and used to create custom SNES Mini Classic custom themes.</p>

<p>An older version of my custom themes can be seen in the youtube video: <a href="https://www.youtube.com/watch?v=W0m67HJ1miw" alt="SNES Classic Custom Themes">https://www.youtube.com/watch?v=W0m67HJ1miw</a></p>

<p>The repository contains the cartridge art & the label artwork separately, so you can assemble your own custom cartridge icon to use as the box art for each game. Everything is in Photoshop format.</p>
